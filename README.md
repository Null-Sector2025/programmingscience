# 编程科学官方网站

## 项目简介

编程科学（Programming Science）官方网站，采用纯HTML/CSS/JavaScript开发，无需任何依赖，直接打开即可运行。

## 特色功能

### 🎬 炫酷进入页
- 二进制0和1代码雨效果（Canvas绘制）
- 代码逐渐聚集形成原子图标
- 3D旋转徽章 + 脉冲发光效果
- 进度条加载 + 状态提示
- 平滑淡出过渡

### 🏛️ 权威设计风格
- 中国红 + 暗金色配色
- 参考中央政府官网设计风格
- 庄重的排版和方正的圆角
- SimHei黑体标题字体
- 金色边框装饰

### 📱 响应式设计
- 完美适配电脑、平板、手机
- 移动端自动调整布局

### 📚 完整内容
- 首页英雄横幅
- 数据统计展示
- 精品书籍推荐（2本）
- 五阶段知识体系时间线
- 关于我们
- 联系我们
- 页脚导航

## 文件结构

```
编程科学官方网站/
├── index.html          # 主页面（包含所有CSS和JS）
└── README.md           # 说明文档
```

## 使用方法

1. 双击 `index.html` 即可在浏览器中打开
2. 无需安装任何依赖，纯静态页面

## 技术栈

- HTML5
- CSS3（动画、渐变、响应式）
- JavaScript（Canvas代码雨、滚动动画、数字滚动）
